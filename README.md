I am a **Machine Learning Engineer & Researcher** with a strong focus on low-resource language processing, multimodal NLP, and LLM evaluation. I am passionate about advancing commonsense reasoning, cross-cultural NLP evaluation, and building reliable language technologies.

### 🔬 What I'm currently working on
- 🏢 **Machine Learning Engineer @ LuccyAi**: Building RAG-based NLP systems, mitigating LLM hallucinations, and engineering robust document processing pipelines using OCR.
- 🎓 **Academic Tutor @ Herald College Kathmandu**: Teaching advanced AI/ML modules, complex systems, and mentoring final-year computer science students in Python and Deep Learning.
- 📝 **Research**: Co-authoring a comprehensive review paper on Natural Language Processing for the Nepali language.

### 🏆 Key Achievements & Publications
- 🏅 **First-Author Publication (LREC-COLING 2026)**: Designed and implemented a transformer-based ensemble architecture for hate speech detection and sentiment analysis in low-resource Nepali multimodal memes.
- 🏅 **Best Computer Vision Project (ReadyTensor International Competition 2024)**: Developed an award-winning multilingual OCR solution capable of recognizing English and Devanagari scripts.
